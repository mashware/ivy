# Design challenge #57

| Angle | Finding | Type (unnecessary/missing/idiom) | Severity |
|-------|---------|----------------------------------|----------|
| 1. Fit | Owner + mode check on the bridge, the helper and opencode is needed. The opencode plugin is the most exposed client: it retries `join(dir,"control.sock")` every 1 s forever (`ivy-opencode.tsx:74`), so a tmux session that outlives its console polls the replantable path for as long as it stays alive. No defensive piece is redundant with what exists: no client checks owner or mode today. | — | — |
| 1. Fit | The `lstat` row's justification is wrong, but the mechanism is harmless. **macOS:** the default `$TMPDIR` is the per-user `0700` `/var/folders/…/T`, so another user cannot plant anything there. **Linux:** `protected_symlinks` already refuses to follow a foreign symlink in a sticky `/tmp`. **With plain `stat`:** a foreign symlink to the attacker's directory fails the uid clause anyway. So `lstat` only adds refusing a symlink to the *same user's* own directory. That sends data to the user's own console, not to another user, so it does not leak. It costs one call, so keep it, but rewrite the reason as "a symlink is never what `PanelDir::create` makes". AC4's "kills `stat`" test protects a property, not a threat. | idiom | low |
| 2. Fragile | All tested scenarios still pass. Genuine directories are always `0700` (`create_dir` sets the mode explicitly, and a umask cannot add bits). The test fixtures pass too: `session_helper.rs` uses `PanelDir::create`, and `plugin.test.mjs` uses Node `mkdtemp` (`0700`, owned by the user). The handshake `nowhere()` case still says "could not be reached at <dir>" because the check sits inside that wrapper. `XDG_RUNTIME_DIR` is the user's own. `ivy_codex_launch.rs` sets `PANEL_DIR="pane directory"`, but that test never connects. | — | — |
| 2. Fragile | The refusal wording is wrong for the most common case. When the directory is missing (a closed console, AC5), the text still reads "not a private directory of this user (…No such file…)". A person reads that as an attack or a permissions problem, not "the console closed". Say "gone" for `NotFound`, and keep "not private" for the uid, mode and symlink failures. | missing | low |
| 2. Fragile | The context says "macOS by default" uses a shared temp directory. That is false when the app is launched from the GUI, because launchd sets a per-user `TMPDIR`. The threat is mainly Linux without `XDG_RUNTIME_DIR`, or an explicitly shared `TMPDIR`. This does not change the fix, but D7's amendment should not repeat the claim. | idiom | low |
| 3. Simplify | No findings. Duplicating the check in JS is unavoidable: the plugin talks to the socket directly. | — | — |
| 4. Operation | `ivy-session` will now forward the raw helper error text, not only the refusal. That error goes into `message` on stdout and onto stderr. Nothing parses `message` (grep: no consumer of `helper_error`). The only new content is the directory path and a uid, which is not sensitive. Acceptable; just note it in the change. | — | low |
| 5. Idiom | The rationale for `mode & 0o077 == 0` is not a checkable reason. A `0o500` directory cannot be "genuine" in any useful sense: its owner cannot bind `control.sock` in it, so the console has no channel to reach. The valid reason is the property itself: "group and others have nothing". Drop the umask argument and the `0o500 passes` edge case. | idiom | low |
| 5. Idiom | No false dichotomies in the other rows. "Inside `connect`/`Producer::of`" vs "the two inherited-identity doors" is correctly argued: the helper bypasses `connect`, and `of` takes the pair as given. "Fail closed" vs "skip if unreadable" leaves no missing option C. | — | — |

**Verdict:** the design is tight. There are no high or medium findings. The fixes are two rationale rewrites, one error-wording split for a missing directory, and one claim to keep out of D7.
