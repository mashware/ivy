# Security design challenge 57

| Angle | Finding | Type (unnecessary/missing/idiom) | Severity (high/medium/low) |
|---|---|---|---|
| Rust/JS predicate | The proposed checks agree: lstat semantics, directory type, effective uid (`geteuid()` / `process.geteuid()`), and reject any `0o077` bits. The mask intentionally allows owner modes other than exactly 0700 and does not inspect special bits, matching the explicit contract. Injecting only the expected uid in a private test helper does not expose a production override. | idiom | low |
| Final symlink spelling | The design does not yet close the trailing-separator case it calls out. On Unix, `lstat("/path/link/")` and `lstat("/path/link/.")` (including Rust `symlink_metadata` and Node `lstatSync`) see a directory and follow the final symlink. Thus either spelling can evade AC4 if the target otherwise passes. Before the metadata check, lexically remove terminal `/` and `/.` components (preserve `/`; do not resolve `..` or canonicalize), while retaining the inherited spelling for diagnostics and connecting through the original path. Add Rust and JS fixtures for both trailing-slash and trailing-dot symlink spellings. Alternatively reject those spellings fail-closed, though that also rejects otherwise valid directory spellings. | missing | medium |
| No-connect evidence | The planned listener-side no-pending-accept assertion is a direct proof that refusal precedes connect, provided it is nonblocking/poll-based and has a finite deadline. It avoids relying on sleeps and is appropriate for both Rust inherited entry points. Keep a positive control to show the listener fixture itself accepts a valid client. | idiom | low |
| Diagnostics and retry lifecycle | The design correctly preserves the guard's path and cause through `ivy-session` (the current binary discards helper error text), while bridge wrapping retains its reachability context. On OpenCode, rechecking at the start of each retry and clearing the timer in `close()` covers refusal and disposal; there is no socket to close on a refused attempt. | idiom | low |
| Scope and races | The check-then-connect pathname replacement race, non-sticky ancestor risk, file-writer exposure, and lack of connected-peer uid authentication are explicitly identified and accepted/out of scope. This design does not claim to authenticate the peer or make pathname validation atomic. | idiom | low |
